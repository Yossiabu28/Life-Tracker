# Life Tracker – הוראות

## פריסה (חינם, כתובת קבועה)
**Netlify (הכי קל):** היכנסו ל-app.netlify.com/drop וגררו את התיקייה. תקבלו כתובת https קבועה.
**GitHub Pages:** צרו repository, העלו את כל הקבצים, ב-Settings > Pages בחרו Branch main. הכתובת: https://USER.github.io/REPO/

## התקנה באייפון
1. פתחו את הכתובת ב-**Safari**.
2. שיתוף > "הוסף למסך הבית".
3. פתחו תמיד מהאייקון. ההתקנה מקטינה את הסיכוי שהנתונים יימחקו.

## סנכרון
ראו את המדריך שניתן בצ'אט (Supabase + config.js).

## איפה הנתונים
IndexedDB בדפדפן, במכשיר בלבד. שום דבר לא נשלח לשרת. התקנה במסך הבית נפרדת מ-Safari הרגיל, ולכן אל תעברו ביניהם אחרי שהתחלתם להזין נתונים בלי לגבות.
החלפת מכשיר או דפדפן: הורדת גיבוי JSON במסך הגדרות, והעברה לייבוא במכשיר החדש. מומלץ לשמור את הגיבוי ב-iCloud Drive.
**גבו לפחות פעם בשבוע.** האפליקציה תזכיר.

## רשימת בדיקה באייפון (סעיף 10)
1. שמרו יום, סגרו את האפליקציה לגמרי, פתחו מחדש: הנתונים נשארו.
2. צרו יום נוסף ובדקו שהקודם לא השתנה.
3. ערכו יום קודם, מחקו יום (ודאו שיש אישור).
4. ייצאו גיבוי, מחקו יום, ייבאו את הגיבוי (מיזוג): היום חזר.
5. בדקו שחזור מלא, ויום עם שדות ריקים.
6. הפעילו מחדש את הטלפון ובדקו שוב. בדקו מצב כהה וטיימר.
